Taruh file PDF buku referensi di folder ini agar tombol "Cari rujukan dari buku" bisa mencari isinya.

Nama file harus sama dengan properti "pdf" di js/data.js:
  ipa-smplb-smalb.pdf          -> Ilmu Pengetahuan Alam (IPA) Fase D-F
  matematika-sdlb-smalb.pdf    -> Matematika Fase A-F

Buku lain: tambahkan entri baru di bagian "buku" pada js/data.js,
atau unggah langsung lewat tombol "Tambah buku (PDF)" di aplikasi (hanya untuk sesi itu).
